# Уборка — приложение для домашней уборки вдвоём

Веб-приложение: картинка комнаты с метками на предметах → инструкция → кнопка «Готово!».
Вход по email (magic link), без паролей. Ты — админ, можешь добавлять/редактировать
комнаты и задачи и сбрасывать выполненные задачи по периодам (неделя/месяц/год).

## Что внутри

- Next.js (один сервис, легко деплоить на Railway)
- PostgreSQL (через Prisma)
- Вход по ссылке из письма (magic link)
- Админ-панель: комнаты, задачи с меткой на картинке, приглашения, сброс по периоду

## Деплой на Railway (пошагово)

1. **Создай репозиторий на GitHub** и залей туда содержимое этой папки (без `node_modules`).
2. **В Railway**: New Project → Deploy from GitHub repo → выбери репозиторий.
3. **Добавь базу данных**: в этом же проекте нажми "+ New" → Database → PostgreSQL.
   Railway сам создаст переменную `DATABASE_URL` и подключит её к твоему сервису
   (проверь в Variables сервиса, что `DATABASE_URL` подставилась — обычно автоматически через "Reference").
4. **Переменные окружения** (Settings → Variables твоего сервиса), по примеру `.env.example`:
   - `SESSION_SECRET` — любая длинная случайная строка
   - `APP_URL` — публичный домен сервиса (Railway выдаёт его в Settings → Networking → Generate Domain), например `https://cleaning-app-production.up.railway.app`
   - `ADMIN_EMAIL` — твой email, станет админом при первом запуске
   - `ADMIN_NAME` — как показывать твоё имя (необязательно)
   - `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` — для отправки писем
     (проще всего завести бесплатный аккаунт на [resend.com](https://resend.com) — там сразу
     даются SMTP-данные; либо используй Gmail с "паролем приложения").
5. Railway сам выполнит `npm install` и `npm run build` (build включает `prisma generate`).
   Миграции (`prisma migrate deploy`) запускаются отдельно как **pre-deploy command** — это
   уже настроено в `railway.json`, — потому что во время сборки (build) приватная сеть
   Railway (`postgres.railway.internal`) ещё недоступна, и подключиться к базе можно только
   на этапе deploy.
6. **Создай первые данные** (админ-пользователь + 5 стартовых комнат с примерами задач):
   в Railway открой вкладку "Shell" для сервиса (или запусти one-off command) и выполни:
   ```
   npm run seed
   ```
   Это создаст тебя как админа и добавит 5 комнат (Кухня, Спальня, Ванная, Гостиная,
   Прихожая) с несколькими примерами задач — дальше ты всё отредактируешь под себя
   через `/admin`.
7. Открой свой домен → введи свой `ADMIN_EMAIL` на странице входа → проверь почту →
   перейди по ссылке. Дальше зайди в «Админ» и пригласи мужа по его email — ему придёт
   письмо со ссылкой для входа.

## Как задать свои комнаты, задачи и картинки

Всё делается в `/admin`, без кода:

- **Добавить комнату**: название + ссылка на картинку. Картинку можно:
  - положить в папку `public/rooms/` в репозитории (например `public/rooms/my-kitchen.jpg`)
    и указать путь `/rooms/my-kitchen.jpg` — потребуется редеплой после добавления файла;
  - либо использовать любую прямую ссылку на изображение в интернете (https://...).
- **Добавить задачу**: кликни по картинке комнаты в том месте, где находится предмет —
  появится метка. Впиши название и инструкцию, выбери периодичность (неделя/месяц/год),
  нажми «Добавить задачу».
- **Изменить/удалить задачу**: прямо в списке под картинкой.
- **Сброс**: во вкладке «Сброс» — сбросить все недельные/месячные/годовые задачи разом,
  сбросить конкретную комнату, или сбросить вообще всё.

## Локальный запуск (по желанию, для проверки перед деплоем)

```bash
cp .env.example .env   # заполни своими значениями, DATABASE_URL можно на локальный Postgres
npm install
npx prisma migrate dev --name init
npm run seed
npm run dev
```

Открой http://localhost:3000
